# Craftfair / Hunarmand source

Public event-list discovery and individual event/call reading, including application status and deadlines. The preset requests English labels; original body text is preserved. Unknown event dates, fees and eligibility stay unknown. A registration countdown is never used as the event date.

Use with the Harvest engine through `AddOcharoEventSources`. No HTTP, registration submission or model call occurs inside the reader. Only observed public listing links are followed; directory coverage is a window.
