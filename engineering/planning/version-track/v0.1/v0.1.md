### Iteration 12 — Service access, browser sign-in and the SCFD brand

`d77daf6` replaced API-key console access with scoped service access: an Identity issuer's audience-bound
`client_credentials` tokens, mapped to an operator or a tenant by `Harvest:ServiceAccess:ClientGrantsJson`.
Browser sign-in returns beside it: an Identity authorization-code BFF that binds a person's organization to one
SCFD tenant, with `harvest:` organization permissions and named operator subjects. Subscriptions accept
`tag:<value>` filters (`DeliveryTagFilter`). A pipeline scope can keep its work under the starting URL's path, and the
console's source picker offers those sections. The product, solution and console carry the SCFD brand; the product id
stays `harvest`.

Verification on 2026-11-10 with SDK 10.0.403: 436 backend tests pass (170 unit, 52 integration, 162 conformance,
5 migration, 47 E2E). Frontend: 35 tests, type checks, format check and production build pass; lint reports 7
warnings and no errors. No deployed target was checked.

- [ ] Ability to pull a tenant's subscription with a consumer's service token, and be refused another tenant's

### Iteration 13 — Events consumer contract

For the Events integration (wow-two-ws `system/sessions/events-integration`, #15–#19). Identity scopes are
`harvest.{noun}-{verb}` under the `harvest` resource, so `events:read` is granted by `harvest.events-read` and no
longer by `events.read`. The Client sends a client-credentials token from `HarvestClientOptions.Identity` on every
broker, through the be sdk's `Http.Auth`. `wow2.event.v1` fills `organizer` only from a declared organizer, adds
`postedAt` and a `mapping` stamp (`rules@4`), and carries the newest `capture`; each pulled `DeliveryEvent` names its
`pipelineId`. Pins: be sdk `10.0.111-beta`, Identity `10.0.30-beta`, whose API keys gain six check characters.

Verification on 2026-11-10 with SDK 10.0.403: 442 backend tests pass (176 unit, 52 integration, 162 conformance,
5 migration, 47 E2E); frontend type checks, tests and format check pass. Under a load average near 220 one robots
rule test timed out in its regex and passed alone. No deployed target was checked.

The dev Afisha sample (adapters `v0.1.4`, 2026-11-10) delivered one fashion event with dates, place, geo, offer,
`postedAt` and the mapping stamp, but its `place` and `postedAt` enums travelled as numbers. The mapper now writes
camelCase string enums, and a stored projection carrying the stamp renders again through the current mapper; a
reader's own projection is sent as stored. 442 backend tests pass.

- [ ] Ability to pull a `wow2.event.v1` record on dev with Events' `harvest.events-read` token
- [ ] Ability to refuse that token on operator routes and on another tenant's subscription
