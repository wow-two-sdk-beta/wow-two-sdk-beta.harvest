# v0.1 — Harvest engine

*Last updated: 2026-10-27*

**Status:** 🚧 In Progress · **Type:** Feature · **Started:** 2026-10-27 · **Completed:** —

Implementation for iterations 2–8 is available. Their acceptance checkboxes remain open for the developer's review;
the verification checklist is the developer's manual pass.

### Iteration 1 — Foundation

- [x] Ability to run Harvest on PostgreSQL with its schema applied on boot
- [x] Ability to refuse boot when trigram or UTF-8 support is missing
- [x] Ability to register tenants, API keys, containers and sources
- [x] Ability to declare pipelines with steps, schedules and scopes

### Iteration 2 — Fetching

- [ ] Ability to fetch pages with per-host pacing and a robots policy
- [ ] Ability to honour `Retry-After` and conditional requests
- [ ] Ability to tell a challenge from a block and a rate limit

### Iteration 3 — Engine

- [ ] Ability to run pipelines on schedule as claimed step work
- [ ] Ability to resume a sweep after a worker dies mid-run
- [ ] Ability to sweep a whole site from its sitemap
- [ ] Ability to re-check known links on their own schedule

### Iteration 4 — Reading

- [ ] Ability to read JSON-LD events from pages
- [ ] Ability to read RSS and ICS feeds
- [ ] Ability to capture plain pages with their links and media

### Iteration 5 — Extraction

- [ ] Ability to extract a post with dates, prices and language by rules
- [ ] Ability to extract contact numbers as normalized plain text
- [ ] Ability to map schema.org events into `wow2.event.v1`

### Iteration 6 — Posts

- [ ] Ability to merge one post seen through several links
- [ ] Ability to see which link supplied each field of a post
- [ ] Ability to undo a wrong merge and keep the pair apart
- [ ] Ability to mark a removed post suspect, then gone

### Iteration 7 — Delivery

- [ ] Ability for a product to subscribe to a pipeline
- [ ] Ability to pull new and changed posts from a resumable cursor

### Iteration 8 — Console

- [ ] Ability to manage pipelines, sources and subscriptions
- [ ] Ability to watch runs, the queue and host health live
- [ ] Ability to browse posts with their links and field sources

### Iteration 9 — Verification

Automated acceptance on 2026-10-27: 351 backend tests pass (127 unit, 39 integration, 5 migration,
150 conformance, 30 HTTP/E2E); 15 frontend tests pass. Frontend type checking, clean lint, formatting,
production build and packed-consumer export checks pass. Offline mstar.uz/voyage.uz fixtures cover sweeps,
unchanged delivery, disappearance, dead-worker recovery, late-result fencing, refusal backoff and item budgets.
The four backend packages build, and a throwaway packed consumer resolves every module and HTTP broker.
The built console's disconnected screen was inspected in the browser. No live-source or production check is claimed.
